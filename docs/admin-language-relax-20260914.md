## 변경 범위

1. 제목·선정 이유·댓글을 통화 표기, 원문 금액 일치 여부로 탈락시키는 검사를 제거했다.
2. 제목 한 줄 5–18자 강제 검사를 일반 후보 스키마의 1–40자로 완화했다. 초과분은 기존 스키마의 잘라내기 처리를 사용한다. 두 줄 전체에는 기존 80자 제한이 유지된다.

잘못된 출력 언어, 댓글 길이·중복, 영상 시간·겹침, 권한·워커 신원 검사는 유지했다. 자막 번역의 숫자·통화 검사는 변경하지 않았다. 프롬프트·문화 설정·모델도 변경하지 않았다.
