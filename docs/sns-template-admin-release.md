## 구현 계약

관리자만 명시적으로 SNS 템플릿을 선택할 수 있다. 서버에서 DB 관리자 권한을 다시
검사한다. 흰 배경, 브랜드 컬러 제목 배너 및 자동 흑백 대비, 동일한 제목/본문 폰트
크기, 5개 실제 영상 비율, 둥근 영상, 채널 행과 정적인 볼륨 아이콘을 합성한다.
4:5·9:16 본문은 한 줄, 나머지는 두 줄이며 해시태그 3개는 16:9·5:4에만 표시한다.
9:16의 게시물 텍스트 시작점은 영상 왼쪽에 맞춘다.

기존 구간 선정은 보존한다. 선정된 제목·장면·전사문을 근거로 한 줄 제목, 본문 배열,
해시태그 배열을 생성하고 글자 수와 실제 폰트 너비를 모두 검사한다. 최대 2회 생성
후 자격 증명 누락·실패에는 원문 기반 대체 문구를 사용한다. 결과는 쇼츠별 템플릿
스냅샷에 저장해 렌더 재시도 시 문구를 유지한다. 편집 기능은 이번 시험 범위 밖이다.

SNS 릴리스는 기존의 검증된 immutable release 배정 구조만 재사용하며, 별도 ID와
고유한 작업 정의를 추가한다. 운영 submitter 코드·일반 registry·언어 settings는
수정하지 않는다. 새로운 워커는 SNS marker를 검사하고 일반 작업을 거절한다.
일반 워커로 SNS 작업을 보내는 fallback은 없다. 테이블/컬럼 변경은 없다. `202609300001_sns_admin_generation.sql`은 관리자 전용 SNS
검증 함수를 추가하고 기존 접수 함수의 처음에 SNS 분기만 삽입한다. 일반 작업 검사
본문은 그대로 보존하며 실제 PostgreSQL 엔진에서 공개/관리자 접근을 함께 검사한다.

## 검증·배포

- 한국어·영어·일본어 문구 제한 및 overflow, 관리자 권한, release identity 검증.
- 5개 비율 FFmpeg/ffprobe 합성, 둥근 모서리, 오디오, 9:16 상하 경계 보존.
- 저장소 전체 검사 후 깨끗한 커밋에서 이미지 빌드; digest와 폰트 identity를 검증.
- 정확한 새 작업 정의·릴리스만 등록하고 관리자만 접수하도록 한다.
- 운영 환경을 사용하는 무별칭 후보에서 보호 경로와 기존 접수 fingerprint 검증.
- 직전 실제 운영 웹을 다시 확인한 후 해당 후보 그대로 승격한다.
- 관리자 원본 1개부터 순차 시험하고 필요한 비율/언어를 추가한다.
  기존 서비스를 이용한 빌드·AI·단기 Fargate·스토리지 비용은 약 5천~3만원으로
  예상하며, 작업/재시도/시간을 제한한다. 상시 유료 자원은 새로 만들지 않는다.
- 실제 테스트 소스·이미지·후보 URL·결과 및 미확인 사항은 실행 증거에 기록한다.

## 실제 생성 중 보완

첫 관리자 프로젝트 `/17453`에서 가로 원본을 9:16에 contain으로 배치하면 큰 여백이
생기는 것을 확인했다. 모든 선택 비율에서 영상 프레임을 채우는 cover로 통일하고,
9:16 원본의 전체 높이 보존과 가로 원본의 세로 프레임 채우기를 별도로 검사한다.
이미 생성된 결과의 릴리스는 보존하며, 후속 전용 릴리스
`8dc98fc0-a5bb-411f-9cc6-0e8dc28648ca`를 사용한다. SNS DB 검사는 등록된 검증 자료의
`kind=sns_admin_generation_only`와 관리자 권한, 정확한 타깃 identity를 함께 요구한다.
일반 작업의 접수 검사와 공개 포인터는 계속 동일하다.

## SNS 편집 후속 릴리스

운영 기준 `1cc194f9562e52abe092cdc25bf6e1749d8d13c3`에서 편집을 추가한다.
기존 SNS 생성 릴리스 두 개와 일반 사용자 릴리스·설정은 유지한다.
새 SNS 편집 릴리스 ID는 `406dadcf-f290-4eb8-b82e-a6e8c6b40105`다.
`editor_release_checks`의 `isolated/sns_editor_compatibility` 증거가 등록된 뒤에만
관리자 소유 SNS 결과를 이 편집 릴리스로 배정한다. 웹, 제출기, 워커가 원래 SNS
생성 릴리스 ID, 관리자 권한, 요청 릴리스, 정확한 소스·이미지·폰트를 각각 검증한다.
다른 언어 테스트 프로젝트는 원래의 동일 릴리스 조건을 유지한다.

편집 경로는 기존 프로젝트의 `/edit/`와 `apply-edit` 요청·outbox를 재사용한다.
SNS 전용 화면은 제목, 정해진 행 수의 본문, 지원 비율의 해시태그, 브랜드 색,
채널명·사진, 영상 시작·끝을 수정한다. 템플릿이나 비율을 다른 것으로 바꾸지 않는다.
본문과 색은 `template.snapshot`에 저장되어 실제 FFmpeg 출력과 다음 편집에 유지된다.
실패 시 기존 완성 영상을 유지하는 기존 편집 완료 트랜잭션을 사용한다.

검증: 5개 비율×3개 언어 문구 계약, 5개 비율 FFmpeg 편집 출력·오디오·라운드·볼륨,
관리자/릴리스 교차 요청 거절, 전체 저장소 검사, 배포 이미지의 15개 합성 편집,
기존 관리자 프로젝트 17454의 실제 편집→반영→재열기 확인. 실제 수행 결과는
`output/sns-editor-release/`에 별도 기록한다. 합성 검사와 실제 관리자 테스트는
서로 다른 증거이며, 완료 전 결과를 성공으로 간주하지 않는다.

필요 자원은 기존 ECR, Batch 큐, S3, DB이며 새 유휴 고정비가 없다.
검증은 최대 900초 합성 작업 1회와 1200초 제한 편집 요청으로 시작하고, 실패 시
원인을 수정한 뒤 제한된 재시도만 수행한다. 예상 종량제 비용은 수 달러 이내다.
공개 worker target registry·editor pointer와 운영 제출기의 나머지 파일은 그대로 둔다.
