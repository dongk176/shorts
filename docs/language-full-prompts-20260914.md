## 변경 범위와 유지 사항

`source_language`가 있는 언어 테스트의 영어·일본어 출력에만 새 장면 선택 지시문을 적용한다. 일반 프로젝트의 `source_language=None` 경로와 한국어 출력은 기존 문구를 유지한다.

| 단계 | 적용 |
| --- | --- |
| 장면 선택·후킹 제목·선정 이유 | 한국어 중심 지시문을 출력 언어의 전체 지시문으로 교체. 사용자 메시지의 안내·표제도 현지화 |
| 제목 보완 요청 | 영어·일본어를 유지하며 긍정형 문장으로 정리 |
| 제목·댓글 공통 언어 문맥 | 영어·일본어의 부정형을 같은 의미의 긍정형으로 정리. 웹·워커 JSON 일치 유지 |
| 문화별 댓글 생성·재생성 | 이미 해당 언어 전체 지시문 사용. 문화 표현·35/25/20/20 비율·모델 그대로 유지 |
| 영어·일본어 자막 번역 | 이미 해당 언어였으며 부정형 지시를 긍정형으로 정리 |

새 지시문에는 출력 예시와 `don't`를 넣지 않았다. 일본어는 자연스러운 생략·짧은 호흡·여운을, 영어는 간결한 구어체·명확한 주체·말의 리듬을 반영한다. 원본 제목·대본은 자료이므로 원문 그대로 전달한다. API 필드명과 JSON 구조도 유지한다.

검사 함수, 개수 조건, 30–120초 범위, 최대 5초 중복, 제목 각 줄 5–18자, 점수 체계, 보완 횟수, 대체 모델, 실패 처리, 일반 워커 대상, 큐, 템플릿, 렌더러는 바꾸지 않았다. 검사 완화·새 검수 단계·새 AI 심사 호출을 추가하지 않았다.

## 내용 품질 검토

원본 대본과 새 제목·선정 이유·댓글을 읽어 비교했다. 일본어는 AI 학습·외부 도구 연계·수해 시설이라는 장면 내용에 대체로 맞았다. 영어도 기술 리뷰·야구 판정에 연결되는 반응이 대부분이었다. 다만 다음 한계가 남아 있다.

- 11932: `ベースモデルとの違いが全然違って`처럼 중복되는 표현이 한 개 있다. 추천 링크 구간을 선택하면서 가입을 권하는 댓글이 여럿 나왔다. `800ポイント`는 저장 대본의 깨진 숫자 표기 `八角`만으로 정확성을 확인할 수 없다.
- 11938: 제목 `居酒屋が店内で受けた被害`는 다소 딱딱하다. 바닥이 반짝인다는 표현과 전문가 뒤의 자료 등 일부 시각 묘사는 대본만으로 확인할 수 없다.
- 11941: 제목 `Surface Duo / Is Back?!`는 원문의 “Surface Duo의 좋은 하드웨어 부분이 떠오른다”보다 강해서 실제 재출시처럼 읽힐 수 있다. `No multitasking?` 댓글은 원문의 용도 차이를 기능 부재로 과장한다.
- 11941: AI 댓글 `Apple's foldable is gonna be $2500 then`이 기존 금액 검사에서 제외됐고 `There is a lot to think about here`로 보충됐다. 기본 댓글은 이 한 개다.
- 11944: `Change MLB? / Umpire Fix`, `With Video Science`는 뜻은 연결되지만 표현이 어색하다. 마지막 선택 구간에는 원본의 Amazon 광고가 포함돼 관련 댓글도 나왔다. 이 단계에서는 광고 제외나 내용 재심사 로직을 넣지 않았다.

따라서 언어 통일과 생성 완료는 확인했지만 제목의 자연스러움·사실의 강도·구간의 마무리까지 전부 우수하다고 평가하지 않는다.

## 자막 표본

기존 대본에서 일본어→영어 3개 조각, 영어→일본어 5개 조각을 실제 기존 번역기로 처리했다. 총 8개 조각의 번역을 받았고 시간값 보존·기존 검사 통과를 확인했다. 원본 일본어의 두 차량이라는 수량과 영어의 세 기종·제품명은 유지됐다.

영어의 `increasing order of interestingness`는 일본어 `興味深い順`으로 번역돼 오름차순이라는 방향이 명확하지 않다. 이 역시 기존 검사를 통과해도 의미 세부까지 완전함을 보장하지 않는 표본이다. 완성 영상 자막 타이밍과 전체 번역 품질은 이번 표본에 포함되지 않는다.

- `make verify` 최종 종료 코드 0: Python/웹 lint, worker 테스트, 웹 2,725개 통과·128개 조건부 검사 건너뜀, 스크립트 206개 통과, 인프라 36개 통과, 타입 검사, Next.js 빌드, CDK synth 완료.

- 로컬 빌드에서 `home_initial_state_failed` 경고가 있었다. 운영 DB 설정 없는 로컬 빌드이며 인증된 홈 데이터 로딩을 검증한 것은 아니다.
