## 손잡이 중심으로 정리

## 편집 UI를 더 단순하게 정리

- `codex/editor-usability-20261007`의 `96b12420c583c2ed213a837f0b33301f7921b0dd` 이후 변경이다. 기존 운영 기준 `cc9eab8461f1f033b888b96457eef0aa5abb61b3`에서 분리한 같은 작업 트리를 사용했다. 운영/DB/worker 변경 및 배포는 하지 않았다.
- 선택한 텍스트는 내용·폰트·색상·효과만 바로 보여 준다. 추가 버튼과 전체 목록은 텍스트 도구 메뉴에서 보여 주며, PC에서 텍스트 도구를 다시 누르면 목록으로 돌아간다. 아코디언 상태와 관련 스타일을 제거했다. 모바일은 완료 → 선택 해제 → 텍스트 메뉴로 전체 목록에 접근한다.
- 모바일에서 선택한 항목의 수정창이 열려 있으면 하단 내용 수정·삭제·선택 해제 줄을 숨긴다. 완료로 입력을 확정하고 원래 타임라인 선택을 유지하는 동작은 그대로다. 선택하지 않은 상태의 도구 메뉴에서는 기존 도구 전환을 유지한다.
- 분할은 영상 조각 또는 미리보기 영상을 선택한 경우에만 표시한다. 텍스트·댓글 등을 고를 때는 숨긴다. 분할 처리와 기존 키보드 동작은 변경하지 않았다.
- PC 미리보기 옆의 별도 레이어 순서 상자를 제거하고 선택한 항목의 설정 아래에 앞으로·뒤로를 배치했다. 영상 선택에서도 같은 사이드바로 접근하고, 제목/영상 순서 제한과 채널 맨앞 고정은 유지한다. 모바일에는 기존처럼 이 조절을 추가하지 않았다.
- 댓글 입력의 반복 제목은 내용과 글자 수 한 줄로 줄였다. 자막 글씨체/폰트 중복 라벨을 없애고 편집 도구의 후킹 제목을 제목으로 줄였다. 저장 문서, API, worker, 템플릿 커스텀 및 global CSS는 변경하지 않았다.
