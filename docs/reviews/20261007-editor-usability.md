## 변경

- 타임라인의 댓글·추가 텍스트를 한 번 선택하면 내용과 시간 설정이 열린다. 모바일 미리보기의 제목·댓글·추가 텍스트·자막도 움직임 없는 탭을 완료한 뒤 설정을 연다. 드래그 중에는 모바일 시트를 열지 않는다.
- 모바일의 중복 댓글 편집 경로를 `내용·시간` 하나로 통합했다. 기존 레거시 편집기의 팝오버는 보존했다.
- 댓글·추가 텍스트에 시작·종료 초 입력과 ±0.1초 버튼을 추가했다. 기존 최소 길이 0.3초, 영상 범위, 인접 댓글의 경계 제한을 재사용한다. 댓글은 미리보기 시간에서 기존 저장 시간으로 환산하는 경로를 그대로 사용한다.
- 자막은 기존 cue draft/commit 및 되돌리기를 통해 패널에서 직접 문구를 바꾼다. 자막 타이밍 지원 범위와 릴리스 제한은 변경하지 않았다. 제목이 영상 전체에 표시된다는 안내를 추가했다.
- 모바일 댓글·텍스트 타임라인 손잡이는 24×44px로 표시하고 바깥 방향의 44px 터치 영역을 제공한다. 시작·종료 손잡이는 구간 바깥으로 분리했다. 숫자 입력과 ± 버튼도 높이 44px 이상이다.
- 모바일에서는 시작·종료 입력을 나란히 표시한다. 새 안내와 접근성 라벨에 영어·일본어 번역을 추가했다.
- 저장 문서 형식, API, worker, 권한, 게시 기능 및 유지보수 게이트는 변경하지 않았다.
