## 후속 구현 순서

### 1 기본 자막형 추가

추천 명칭은 「ベーシック字幕」다. 말하는 단어마다 색·크기가 바뀌지 않는 읽기 쉬운 자막으로 제공한다. 내부 렌더 규격과 워커에는 basic 처리 기반이 있으나, 사용자가 고르는 템플릿과 커스텀 템플릿 스키마는 highlight·pop 중심이므로 버튼만 추가해서는 끝나지 않는다.

1. 기존 basic 렌더 경로와 현재 운영 워커 지원 범위를 대조한다. 글자색·외곽선·배경·위치의 기본값을 정한다.
2. 생성 화면과 라이브러리에 기본형을 추가하고, 선택값→작업 요청→저장된 템플릿→편집기까지 전달되도록 계약과 검증을 맞춘다. 기존 템플릿을 읽는 동작은 유지한다.
3. 미리보기와 출력 영상이 같은 규격을 사용하도록 연결한다. 필요한 경우 새 워커 리비전을 등록하되 기존 프로젝트가 참조하는 워커는 보존한다.
4. 한국어·일본어·영어의 짧은 문장/긴 문장/무음 구간을 비교하고, 편집 후 저장·다운로드까지 검증한다. 렌더러 변경 시 기존 FFmpeg/ffprobe 합성 통합 검사를 유지한다.

완료 기준은 세 언어의 기본형 미리보기·출력이 일치하고, 기존 팝업형·강조형과 저장된 프로젝트가 깨지지 않는 것이다. 예상 작업량은 호환성 확인 결과에 따라 약 2~3일이다. 실제 제작 테스트가 필요해지면 운영 코드 기준과 격리된 테스트 설정을 먼저 확정한다.

### 2 일본어 용어와 첫 화면 정리

처리 가능 분량은 処理時間, 실제 기다리는 시간은 完成までの目安로 구분한다. SNS風·コミュニティ風·コメントまとめ·ポップアップ字幕·ハイライト字幕를 용어표로 고정하고, 메뉴·오류·편집기·가이드·대본을 함께 대조한다. 사용자 작성 문구는 일괄 번역 대상에서 제외한다.

첫 화면은 현재 작업 구조를 유지한 두 시안을 비교한다. 추천 제목은 「動画のリンクから / ショート動画をかんたん作成」이며, 설명은 URL→장면 선택→제목·자막 완성의 결과를 보여준다. 로그인 전에는 사용법과 결과 예시를, 로그인 후에는 입력 영역 다음에 최근 프로젝트를 우선한다. 생성 설정을 펼쳤을 때 프로젝트 위치가 작업을 방해하지 않는지도 함께 확인한다.

쇼케이스의 추천 문구는 「見どころをAIで編集 / タイトルも字幕もコメントも」다. 댓글 안내는 「AIが作成したコメントを動画に表示」로 연결해 실제 시청자 댓글 모음으로 오해하지 않게 한다. 데스크톱·390px·360px에서 제목 중복, 일본어 단어 중간 줄바꿈, 글자 잘림을 점검하고 일본어 사용자에게 서비스 결과를 바로 설명할 수 있는지 확인한다. 예상 작업량은 시안·검수 약 1일이다.

### 3 튜토리얼 영상

수정된 화면을 기준으로 60~90초 일본어 영상 한 편을 만든다. 링크 입력→분석 범위 선택→처리시간 확인→세 가지 대표 스타일 비교→원본 권리 확인→생성 결과→간단 편집→다운로드 순서로 녹화한다. 처리시간과 대기시간의 차이, AI 댓글의 의미를 각각 한 번 설명한다.

개인정보 없는 예제와 이용 가능한 원본을 사용하고, 일본어 대본 검수 후 자막을 붙인다. 처음 방문한 사용자는 입력창 주변의 ‘使い方を見る’에서 열고, 기존 사용자는 도움말에서 다시 볼 수 있게 한다. 기본 자막형을 먼저 넣는다면 해당 화면이 확정된 뒤 녹화해 재촬영을 줄인다. 예상 제작량은 화면·대본 확정 후 1~2일이다.

### 4 일본 사용자 후기

일본어로 실제 이용한 사용자에게 사용 목적, 편리했던 점, 개선점을 받아 3~5건부터 준비한다. 사용자가 동의한 원문·표시 이름·직군 범위로 게재하고, 후기 문장을 기능 약속으로 과장하지 않는다. 수집 전에는 기존 번역 후기를 일본인 후기인 것처럼 바꾸지 않는다. 소요 기간은 사용자 응답에 달려 있으며, 후기가 확보된 뒤 카드 구현·검수는 약 반나절로 예상한다. 이번 작업에서 후기 요청 메시지를 발송하지 않았다.
