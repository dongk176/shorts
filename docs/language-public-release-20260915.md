# 언어 기능 공개 제어

## 운영 방법

관리자 페이지의 **언어 기능 → 일반 사용자 공개**에서 ON/OFF를 바꾼다.
최초 배포는 OFF이며 관리자 제작과 튜토리얼은 이용할 수 있다. ON은 모든 계정에
즉시 적용된다. OFF는 일반 계정의 신규 언어 제작만 차단하며, 접수된 작업과
기존 프로젝트의 저장된 언어·워커·편집·다운로드 연결은 유지한다.

ON/OFF 저장은 재배포와 확인 팝업 없이 적용된다. 실행 연결의 검증이 완료되지
않으면 ON을 차단하며 OFF는 가능하다. 저장 응답을 잃어도 저장된 상태를 다시 조회한다.
`enabled`는 기존 실행 연결 설정으로 유지하고, 관리자 화면은 `publicEnabled`만 변경한다.

## 저장과 권한

- `language_test_settings.public_rollout_percent`는 기존 식별자를 유지하되 0/100만 허용한다.
  API의 `publicEnabled`는 이 값이 100인지로 결정하므로 별도 중복 공개 설정이 없다.
- 관리자 설정 변경은 기존 감사 테이블에 관리자·시각·공개 상태·실행 상태·릴리스를 저장한다.
- 화면/API/DB 모두 관리자이거나 공개 ON인 로그인 계정을 허용한다.
- 구형 요청의 `outputLanguage`/`sourceLanguage`도 언어 기능 의도로 판별한다.
  내부 표시를 생략해도 공개 OFF를 우회하지 못한다. 언어 값이 없는 구형 한국어 요청은 유지한다.
- 계정별 기존 트랜잭션 잠금·요금제·한도·중복 요청 검사를 유지한다. 전역 한 작업 제한은 제거한다.
  공개 변경은 독점 잠금, 접수는 공유 잠금으로 순서를 보장한다.
- `language_guide_views.dont_show_again`은 ‘다시 보지 않기’ 선택만 계정별로 저장한다.
  확인·닫기·Escape는 이번 안내만 닫으며 다음 제작에서 다시 표시한다. 기존 닫기/완료 기록은
  자동 숨김으로 취급하지 않는다. 공개 OFF 일반 계정은 기록하지 않는다.
  계정이 바뀐 탭의 지연 저장은 차단한다. 안내 조회/저장 실패는 제작을 막지 않는다.

## 화면

구간 안내 → 영상 언어/제작 언어 안내 → 자막 템플릿 안내 순서다.
언어 안내의 ‘사용 방법’으로 다시 볼 수 있다. 한국어·영어·일본어, 키보드 이동과
닫기, 좁은 화면에서의 스크롤을 지원한다. 제작 언어는 홈 언어를 따르며 직접 선택한
값은 같은 영상의 준비 과정과 메타데이터 재조회·홈 언어 변경 중 유지한다.
새 영상이나 제작 완료 후에는 홈 언어를 다시 기본값으로 사용한다.

## 릴리스 구성과 검사

웹 기준은 실제 운영 `993052f0d3f492121e186d2d8a3b5352fb14dddb`다.
기존 검증된 워커 `4097b4364919dca4557c2bf1ecba10a77213890c`의 소스를 함께 보존하며
실행 이미지는 새로 빌드하지 않고 기존 릴리스 `a3f68839-d915-48ac-ba32-49d68ded43dc`를 사용한다.
일반 한국어 워커와 전역 편집기 연결은 기존 값을 유지한다.

- `make verify`: 정적 검사, 워커/웹/CDK 검사, 웹 빌드와 인프라 합성.
- 웹 실제 POST 핸들러 검사: OFF/ON, 위조 요청, 구형 요청, 같은 요청 동시 재시도,
  단일 차감, 같은 계정 동시 제출 제한, 서로 다른 계정 허용, 요금제와 사용량 한도.
- 네트워크가 없는 일회용 PostgreSQL: 추가 마이그레이션, 공개 권한, 동시 계정 접수,
  OFF 이후 작업 완료/편집, 언어 연결 불변성, 비로그인 DB 역할의 안내 상태 접근 차단.
- 후보 주소에서 주요 페이지와 실제 관리자 제작·편집·재출력·다운로드를 검사한 뒤
  같은 배포를 승격한다. 운영에서 일반 공개 ON 검사는 수행하지 않는다.

실제 실행 결과와 후보/운영 배포 ID는 이번 작업의 `language-public-gate-20260915-ops`
증거 디렉터리에 저장한다. 배포 완료의 기준은 **관리자 기능 사용 가능, 일반 공개 OFF**다.
