# 업데이트 관리

관리자 → 고객 지원 → 업데이트 관리에서 작성합니다. 기존 /updates 디자인을 재사용합니다.

- 제목, 소개, 날짜, 분류, 주제와 표지 사진/문구를 입력합니다.
- 본문은 글·사진·사용 방법 블록으로 구성하며 위/아래 버튼으로 순서를 바꿉니다.
- 사진은 JPG/PNG/WEBP 3MB 이하입니다. 강조할 위치를 드래그하고 설명을 입력합니다. 키보드로는 번호 표시 추가 → 표시 위치 조절을 사용합니다.
- 미리보기는 실제 상세 페이지와 같은 컴포넌트를 사용합니다.
- 초안 저장은 공개 내용에 영향을 주지 않습니다. 게시하기가 공개 내용을 교체합니다. 숨기면 목록·상세·검색·최근 표시에서 제외됩니다.
- 게시한 글의 주소는 유지됩니다. 미래 날짜의 예약 게시는 지원하지 않습니다.
- 두 창에서 수정하면 이전 버전의 저장은 차단됩니다. 내용을 복사해 둔 뒤 목록을 새로 열어 주세요.

## 운영 구조

shorts_mvp.update_posts의 draft/published를 분리하고 visible로 노출을 제어합니다. 버전 확인과 게시는 같은 트랜잭션에서 실행합니다. shorts_mvp.update_assets는 게시 스냅샷에서 참조할 때만 공개되며 미게시 사진은 관리자 인증이 필요합니다. 공개 사진 캐시는 최대 60초입니다. 원본 파일명·메타데이터는 저장하지 않습니다. 기존 글 참조 보호를 위해 사진을 자동 삭제하지 않습니다.

API는 관리자 인증·동일 출처·입력 크기·서버 검증을 적용합니다. 두 테이블은 RLS를 켜고 anon/authenticated 직접 접근을 차단했습니다. public 스키마는 변경하지 않습니다.

202610010100_update_cms.sql에 기존 글과 캡처 표시를 보존했습니다. posts.json/data.ts는 초기 기록 및 캡처 호환용이며 이후 글 수정은 관리자에서 수행합니다. 공개 페이지·사이트맵·최근 7일 표시는 게시 데이터만 읽습니다.
