## 발견하여 수정한 문제

1. **좁은 화면의 배치:** 320px에서 날짜 버튼 때문에 목록 제목이 두 줄로 눌리고 달력 하단이 화면 밖으로 내려갔다. 제목·버튼이 필요할 때 다음 줄로 배치되게 했고, 모바일 달력은 화면 하단에서 높이를 제한한다. 데스크톱은 남은 공간에 따라 위/아래로 열며 넘치는 내용은 내부에서 스크롤한다.
2. **이미 표시한 카드의 상태:** 새 목록 안내만 표시하던 동안 비공개·라이선스 변경이 기존 카드에 남았다. 최대 200개 ID씩 DB에서 공개 상태·라이선스·24시간 유효성·현재 급상승 여부를 확인한다. 기존 순서를 유지하면서 해당 항목을 제거하거나 표시를 수정한다. 이 확인은 YouTube 요청을 만들지 않는다. 실패한 상태 조회로 영상을 삭제하지 않는다.
3. **만료된 페이지 안내:** 목록이 만료되어 첫 페이지를 다시 불러올 때 안내가 스크롤 위에 가려질 수 있었다. 안내가 보이는 목록 시작점으로 이동한다. 필터 변경 후 늦게 도착하는 이전 요청은 반영하지 않는다.
4. **초기 일일 수집 분류:** 기존 주기의 새 수집을 과거 이행 실행으로 표시하던 문제를 재현해 수정했다. 새 수집은 이행 대상에 다시 들어가지 않으며 임시 호환 목록의 만료와 과거 원본 정리 잠금이 분리된다.
5. **오래된 정보 이행:** 원본과 누적 정보가 모두 오래됐을 때 API 재확인 결과보다 기존 정보가 우선되던 문제를 재현해 수정했다. 정상 응답으로 이용 불가가 확인된 경우에도 옛 정보가 남지 않으며 최초 발견일과 날짜 이력은 유지된다.
6. **한국시간 자정:** 실행 시작일과 실제 발견일이 다르면 다음 날짜에 영상이 있어도 수집 기록 없음으로 보일 수 있었다. 실제 관측 날짜와 실행의 연결을 영구 보존해 월말·자정을 넘긴 기록도 정확히 표시한다. 이 연결 누락도 이행 대조에서 확인한다.
7. **만료 정보와 운영 표시:** 30일이 지나 폐기된 API 정보가 재사용 카운터에 남지 않게 갱신한다. 관리자 화면에는 옛 원본 정리 잠금, 최초 발견일 오류와 만료 정보 수를 표시한다.

## 배포 전 아직 필요한 운영 확인
