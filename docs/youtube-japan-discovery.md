## 수집과 예산

일본은 UTC 08:15(한국·일본 17:15)에 하루 한 번 실행한다.
급상승 7개 카테고리, 재사용 허용 7개 카테고리, 최근 7일 조회수 상위 순환 3개
카테고리의 첫 페이지만 처리한다. 재사용 허용에는 업로드 기간 제한이 없다.
JP·ja를 사용하며 추가 페이지·자동 재검색·일본 무료 소재 수집은 없다.
조회수 카테고리는 7일 동안 각각 3번씩 검색한다.

- 한국 검색 90회, 일본 검색 10회. 프로젝트 검색 합계 상한 100회.
- 한국 일반 예산 9,000유닛과 그중 백그라운드 3,000유닛을 유지한다.
- 일본 일반 예산은 별도 17유닛이며 합계는 9,017유닛이다.
- 일본 검증 만료나 OFF 이후에도 이미 사용한 일본 검색 때문에 한국 몫을 줄이지 않는다.
- 실패·중복·수동 호출도 API 요청 전에 동일 원장에서 원자적으로 예약한다. 예약을 환불하지 않는다.
- 날짜는 미국 태평양 시간 기준이다. 별도 배치 기록으로 같은 날짜의 수동·정기 중복 실행을 막는다.
- HTTP는 순차 실행, 요청당 15초·전체 240초다. HTTP 대기 중 DB 트랜잭션을 유지하지 않는다.
- 설정 조회나 사용량 기록 실패·쿼터 오류·시간 초과 시 새 요청과 해당 종류 결과 게시를 중단한다.
- 원본 조회 함수에는 일본 설정 조회나 수집 잠금을 추가하지 않았다. 정상 API 요청 2회를 유지한다.
- 일본 전용 영상은 한국 정기 재확인에서 제외하고, 30일 정보 유효기간과 폐기 규칙은 유지한다.

[Google 공식 쿼터 기준](https://developers.google.com/youtube/v3/determine_quota_cost)의
기본 검색 100회·기타 10,000유닛은 실제 프로젝트 잔여량을 뜻하지 않는다.
활성화 전에 실제 키 연결, 프로젝트 승인 한도, 최근 사용량과 공유 사용처를 대조한다.
`japan_verified_at`과 구체적인 `japan_evidence`가 있어야 하며 확인은 7일간 유효하다.

## 국가별 회차·목록·언어

조회수 상위·재사용 허용은 종류별·국가별로 가장 최근 성공한 오후 슬롯을 선택한다.
KR 슬롯은 17:10, JP는 17:15이며 모두 17:20 이후에만 활성화한다.
지연·실패한 국가는 이전 회차를 유지하고 다른 국가의 성공을 막지 않는다.
자정이나 한국 오전 수집은 오후 회차를 바꾸지 않는다.

오늘 수집은 각 국가의 활성 슬롯부터, 최근 7일은 그 슬롯의 6일 전부터다.
전체에는 기간 제한을 두지 않고 급상승의 기존 기간 계산을 보존한다.
각 국가 조건을 통과한 영상을 ID로 합쳐 목록과 개수에서 중복 제거한다.
기존 `collectionWindowStart`는 KR 기준이며 `collectionWindows`와
`collectionWindowKey`를 상태·목록 응답에 함께 제공한다.

새 커서는 언어·국가 범위·회차·실행·영상 순서를 고정한다. 같은 회차의 추가 수집은
기존 페이지 순서를 바꾸지 않는다. 오늘·최근 7일은 활성 회차 변경 시 만료시키고,
전체는 기존 수명을 유지한다. 기존 커서는 KR 범위와 기존 회차 만료 규칙을 유지한다.
60초 상태 확인에서 국가별 회차 전환과 일본 노출 OFF를 감지하고 다시 조회한다.
공개 상태·라이선스·30일 유효기간은 페이지 이동 중에도 최신 정보를 적용한다.

일본어는 음성 언어 → 기본 언어 → 둘 다 없을 때 제목의 가나 2자 이상으로 판정한다.
다른 언어 메타데이터를 제목으로 덮어쓰지 않는다. 한자만 있는 제목·채널명·수집 국가는
판정 근거가 아니다. 기존 한국어 판정은 유지한다. 과거 영상은 저장된 제목만 보완한다.
언어 버튼은 배타 선택이고 다시 누르면 전체다. 모바일·한영일·기존 이용 권한·사용 기록에
적용한다. `korean=true&japanese=true`는 400이다. 목록·필터·더 보기는 DB만 읽는다.

## 관리자 설정과 순차 DB 전환

환경 변수 `YOUTUBE_JP_COLLECTION_ENABLED`, `YOUTUBE_JP_DISCOVERY_ENABLED`는 기능 제공
여부다. 둘 다 기본 false다. 준비된 배포에는 true로 제공하되 실제 실행과 노출은
DB의 `japan_collection_enabled`, `japan_discovery_enabled`로 각각 제어한다.
DB 기본값은 OFF이며 관리자 화면에서 재배포 없이 바꾼다. 관리자 인증·동일 출처 검사와
`youtube_japan_settings_audit` 변경 기록을 적용한다. OFF는 다음 API 요청부터 반영한다.
수집 ON에는 최신 쿼터 확인과 DB 전환 완료가, 최초 노출 ON에는 세 종류 성공 기록이 필요하다.

1. 현재 운영 기준, DB 신원과 복구 가능 상태를 확인한다. 두 DB 설정은 OFF로 유지한다.
2. `202609110010_youtube_japan_discovery.sql`과 `202609110011_youtube_japan_quota.sql`만
   먼저 적용한다. 과거 기록은 KR이며 이전 앱의 고유 제약을 보존한다.
3. 깨끗한 커밋에서 별칭 없는 운영 후보를 빌드한다. 기존 예약 작업을 그대로 두고 일본 하나만
   추가한다. `/`, `/guidebook`, `/pricing`, 관리자, 편집기 보호 경로와 로그인·원본 조회를
   검증한다. content-calendar·publishing 실험은 포함하지 않는다.
4. 검증한 동일 후보를 재빌드 없이 승격한다. 이전 실행 종료와 두 설정 OFF를 확인한 뒤
   `202609110012_youtube_japan_activation_constraints.sql`을 적용한다.
   이 마지막 단계는 전환 중 추가된 KR 영상뿐 아니라 기존 영상 갱신도 최종 반영한다.
5. 실제 쿼터 근거를 기록하고 수집만 ON으로 바꾼다. 최초 수집은 현재 예산 안에서 한 번만,
   이미 도래한 최근 17:15 슬롯으로 실행한다. 미래 슬롯 성공 처리나 과거 누락 따라잡기를 하지 않는다.
6. 첫 정상 수집·일본어 표본·원본 조회를 확인한 뒤 노출을 ON으로 바꾼다.
7. 첫 7일 국가별 요청·실패·중복·언어 판정 비율과 원본 조회 오류·응답 시간을 관찰한다.
   검증 만료 전에 실제 근거를 재확인한다. 수집량은 자동 증가시키지 않는다.

문제가 생기면 새 앱에서 일본 수집·노출만 OFF로 바꾼다. 한국 예산·목록은 유지한다.
국가별 제약 전환 후에는 옛 앱을 바로 재배포하지 않는다. 이행을 되돌리는 대신 두 설정으로
복귀하며 영상 이력을 삭제하거나 DB 전체를 복원하지 않는다.

## 검증 재현과 근거

`web/lib/youtube-discovery-postgres.test.ts`는 로컬 `youtube_discovery_test` DB만 허용한다.
단계별 마이그레이션 사이에 옛 앱의 삽입·갱신을 재현하고 최종 보존을 검증한다.
17:20 전후·종류별/국가별 지연·자정·중복·구형/신형 커서·OFF·만료·동시 쿼터·PT 날짜
전환·원본 2회 요청·관리자 권한을 포함한다. 실제 API를 호출하지 않는 검증이다.

릴리스 검증 결과와 실제 배포·활성화 기록은 작업별 운영 기록에 남긴다. 이전 일본 작업본의
검증 결과를 이번 통합본의 통과 근거로 사용하지 않는다.
