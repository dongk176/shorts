## 발견하고 수정한 문제

1. **나중에 표시되는 안내 누락**: 업로드 선택·정보 확인·진행 안내, 첫 로그인 설문의 질문과 선택지, 프로젝트 안내, 마케팅 수신 안내, 피드백 및 결제 관련 안내 등에 한국어가 남았다. 기존 사전에 영어·일본어 번역 315쌍을 추가했다.
2. **문장 조각의 어순**: 선택 영상 길이/예상 쇼츠 수, 처리시간, 자막 타이밍, 배경 삭제 안내, 구독 기간/변경일, 약관 동의 문장을 숫자와 분리해 번역하면서 문법이 어색하거나 한국어 조사가 남았다. 46개 공통 메시지 키를 추가해 문장 전체를 번역했다.
3. **부자연스러운 영어**: `1 Shorts`, `Expires in 1 days`, `Creation language`, 소개 페이지의 `Turn YouTube videos into How to create AI Shorts`를 각각 단수형, `Output language`, `How to turn YouTube videos into AI Shorts`로 보완했다.
4. **일본어 세부 설정**: 제작 언어를 `出力言語`로 정리하고, 모바일에서 긴 영상 비율 라벨은 `縦横比`로 줄였다. 배경·색상 이름과 템플릿 예문, 댓글·자막 샘플의 한국어 누락을 보완했다.
5. **상태 변경 후 접근성 문구**: 번역 처리기가 새로 추가되는 노드만 감시하고 `aria-label`, `placeholder`, `title` 등의 변경은 놓쳤다. 해당 속성의 변경도 감시한다.
6. **콘텐츠 보존**: 영상 제목·채널명·파일명·저장된 배경 이름·사용자가 작성한 영상 문구는 원문으로 유지한다. 번역한 템플릿 예문은 화면 표시용이며 저장된 영상 콘텐츠나 제작 언어를 변경하지 않는다.
7. **과거 약관 안내**: 번역이 없는 약관에도 번역본 안내가 나오는 문제를 고쳐, 한국어 원문만 제공되는 자료임을 명시했다.

## 실제 화면 점검

브라우저에서 최종 표시가 완료된 상태의 문구와 조작을 확인했다. 초기 HTML과 번역 후 화면을 구분했으며, 로딩 중 한국어를 곧바로 미번역으로 집계하지 않았다.

- 한국어 `/`: 영어·일본어 전환 후 복귀, 파일 선택·썸네일·영상 길이 보존.
- 영어·일본어 메인: 로그인, 제작 설정, 원본/출력 언어, 예시 템플릿, 업로드 파일 정보, 후기/공통 메뉴.
- 영문 첫 로그인: 실제 로컬 인증 후 직업 설문 확인. 나머지 선택지는 코드와 번역 회귀 테스트로 확인했다.
- 계정: 영문 설정, 영문 결제·사용 내역, 영문/일문 플랜 관리의 이용권 없는 상태.
- 프로젝트: 목록, 프로젝트 카드의 단수·날짜, 일본어 완성 영상 편집 화면. 저장된 한국어 영상 제목은 유지됐다.
- 템플릿: 일본어 목록과 새 템플릿 편집기의 제목·자막·배경 메뉴. 영문/일문 예문과 사용자 작성 텍스트 보존은 렌더 테스트로도 확인했다.
- 요금제: 영어·일본어 플랜 카드·기간·추가시간·비교표. 결제 관련 조건별 문구는 정적 검사와 테스트로 보완했으며 실제 결제나 해지·환불 요청을 보내지 않았다.
- 공개 안내: 영어·일본어 FAQ, 고객센터, 가이드북, 최신 이용/구매/개인정보/환불 정책, AI 쇼츠 안내, 비교 페이지, PRIVATE 안내, 인기 영상 필터.
- 모바일 390×844: 영문 안내창, 영문·일문 제작 설정, 파일을 선택한 채 언어 전환. 점검 후 화면 크기를 원상 복구했다.

## 최초 점검 당시 남아 있던 현지화 범위

- **첫 로딩의 한국어 노출**: 기존 정적 한국어 문구는 브라우저가 번역을 적용하기 전 잠깐 보일 수 있다. 안정된 화면에서의 미번역과는 별개로, 서버에서 처음부터 번역해 출력하도록 옮기는 후속 작업이 필요하다.
- **블로그**: `/en/blog`, `/jp/blog` 및 글 본문은 별도의 번역 데이터가 없고 한국어 콘텐츠가 남아 있다. 전체 글 번역은 이번 UI 문구 보완에 포함하지 않았다.
- **한국어 자료**: 가이드북·전자책 PDF, 원본 홍보 영상에 포함된 글자, 후기 작성자 이름은 한국어 원본이다. PDF에는 한국어 자료임을 안내하고 있다. 해외용 PDF/영상 제작은 별도 작업이다.
- **과거 약관 및 기업 전용 화면**: 번역 없는 과거 약관, 기업 계약 Markdown 및 일부 기업 플랜 화면은 한국어가 남아 있다. 최신 일반 고객용 정책 페이지와 구분해야 한다.
- **외부 결제창/실제 메일**: Toss 등 외부 결제창, Paddle 연동 화면, 실제 발송 이메일은 이번 로컬 화면 검증 범위 밖이다. 정상 번역으로 판정하지 않았다.

따라서 ‘사이트 전체의 미번역이 0개’라는 결과는 아니다. 주요 제품 UI에서 확인된 문제를 수정했고, 콘텐츠 및 아직 이관되지 않은 영역을 위와 같이 분리했다.
