## 집계 정의

- KST 오늘 포함 7/30/90일 또는 현재 보존된 전체 기록. 직전 동일 일수 비교. 주간은 월요일, 월간은 1일.
- 회원 구분: production conversion_events의 최초 ko/ja/en 기록. 무기록 회원은 unknown.
  거주 국가가 아니다. 2026-11-15 조사 시 39,216계정 중 2,261계정만 분류 가능.
  언어 수집 시작 2026-11-09. 분류된 회원의 과거 이벤트에도 해당 분류 적용.
- 국내 승인일, Paddle/PayPal 정기 결제 수신일, PayPal 단건 완료일.
  실제 운영용 결제만 집계. KRW/JPY는 단위, USD는 센트이며 통화간 합산 없음.
  환불은 원주문의 누적 차감(결제일 코호트), 현금흐름/정산액 아님.
- 해지 요청률: 기간 중 존재한 유료 구독 중 마지막 canceled_at이 기간 내인 구독.
  신규 포함 분모. 전통적인 기간 시작 코호트 이탈률과 다름. 반복 해지/철회 이력은 복원하지 않음.
- 쇼츠: output_s3_key 존재 및 file_size_bytes > 0, 최초 created_at 기준. 예제 제외,
  만료/삭제 이력 포함(기록 보존된 경우), 재편집 중복 없음. 회원 연결 없는 작업 제외.
- 온보딩: completed_at 기준 현재 보존 응답. 이용 목적은 복수선택 횟수 비율.
- 유튜브: 현재 active 연결 수/고유 연결 회원 수. 최초 연결·해제 히스토리가 불충분해
  기간별 신규 연결을 추정하지 않음.
- 현재 회원/활성 구독/연체/해지 예약/채널은 기간 지표와 분리한 현재 스냅샷.

## 구현/검증

관리자 인증 후 고정 SQL과 바인딩된 필터 사용. 서버 합계만 응답, 개인 식별값 없음.
HTTP private no-store, 서버 집계 캐시 300초. 30일+직전30일 실제 운영 SQL EXPLAIN
ANALYZE 약 2.64초. 원본 행은 브라우저로 전송하지 않음. 주/월 변경은 추가 DB 조회 없음.

PDF 저장/인쇄는 같은 집계 스냅샷에 A4 4개 섹션 전용 인쇄 레이아웃 적용.
브라우저의 PDF 저장 사용. 로컬 실제 집계 fixture PDF 4쪽과 한글/차트/표 확인.
서버 및 원장 기준 테스트와 실제 배포 UI 검증은 구분한다.
