# 인기 영상 기간 필터 복구

2026-09-11 사용자 요청: 수집 확대는 유지하고 날짜 선택 달력을 전체 / 오늘 수집 / 최근 7일로 바꾼다. 예전에 수집한 재사용 영상도 모두 볼 수 있어야 한다.

- 세 목록에서 전체를 기본으로 사용한다. 오늘은 한국시간 당일, 최근 7일은 오늘을 포함한 7개 날짜에 실제로 수집한 영상이다. 같은 영상의 재수집을 포함하며 중복 카드는 만들지 않는다.
- 급상승의 전체는 과거 급상승 등장분까지 포함한다. 최신 급상승 실행에 나온 영상을 먼저 표시한다.
- 재사용 허용을 켜면 어느 수집 경로로 들어왔는지와 무관하게 현재 공개 CC 영상을 합친다. 급상승에서 이 필터를 켜도 24시간으로 제한하지 않는다.
- 확인 시각 갱신은 수집으로 세지 않는다. 최초 발견일도 바꾸지 않는다. `youtube_collection_recency`는 마지막 실제 수집 시각만 별도 보존하며 원본 스냅샷이나 날짜 이력을 변경하지 않는다. 백필은 남아 있는 세 수집 원본과 실행 연결을 사용한다.
- 화면에서 달력만 제거한다. 기존 날짜 이력 및 날짜 조회 API는 보존한다. 기존 API 계약은 유지하고, 새 화면만 `periodBasis=collected`를 보낸다. 커서는 조회 기준별로 구분한다.
- 공개 상태/라이선스 변경과 API 정보 보존 기준은 유지한다. 과거 영상도 재사용 허용으로 현재 확인된 경우에만 표시한다.

수집 일정, 할당량 한도, 기능 플래그, 워커 설정은 변경하지 않는다. 급상승 홀수 시 정각, 조회수 상위·재사용 05:10/17:10, 무료 소재 17:40, 재확인 15분 주기 그대로다.

검증은 로컬 격리 DB·모의 응답과 기존 로컬 브라우저/배포 자원으로 수행한다. YouTube 재수집이나 영상 생성 비용은 필요하지 않다. 기존 후보 배포 한 번과 소규모 DB 읽기/별도 수집시각 복원만 예상한다. 고정 유료 자원은 추가하지 않는다.
